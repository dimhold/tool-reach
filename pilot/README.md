# Pilot, 2026-08-26. Excluded from every number.

One opus pass over all ten questions, run before the measurement proper. It
found a defect in **our own instrument**, not in the model:
`world_bank_indicator` returned only the 8 most recent observations, which made
the control question about Poland's population in 2000 unanswerable in
principle.

The model said so plainly — "the World Bank tool only returns the most recent
years" — and had this pass counted, that honesty would have been recorded in the
table as a refusal to answer.

The tool was fixed (70 observations). The pilot is kept here as an exhibit and
contributes nothing to the results.
